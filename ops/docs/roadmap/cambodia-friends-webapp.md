# Cambodia, friend play, and web-app continuation

## Delivered

- Cambodia has its own `ouk-chaktrang` variant and home card, native Khmer name, asymmetric royal setup, opening leaps, permanent king-leap restrictions, sixth-rank promotion, plain board, piece names, and an original SVG collection. The catalog now has 21 board adapters, with Cambodia explicitly in local/bot preview while competitive verification is unfinished. Published digital counting and three teaching positions are now implemented; see `ouk-counting-profile.md`.
- Original Higgsfield/Blender collection: six carved shapes in two materials. The editable `.blend`, portable `.glb`, and rendered preview are committed with provenance in `ops/assets/khmer/README.md`. Optional interactive 3D supports tapping moves, orbiting, zooming, board rotation, and themes. It loads only on demand, remembers the view, reuses geometry, avoids redraws for clock-only updates, and retains the accessible 2D option.
- Classic chess and seven modern variants now have their own original ivory/walnut Blender collection. The shared 3D renderer offers real porcelain/slate materials, an adjustable angled camera with reset, small unboxed edge coordinates, move markers, promotion rings, and safe 2D recovery. Preferences remain specific to each game. See `ops/assets/classic/README.md`.
- Shogi and Mini Shogi now have a separate original Blender tile collection: 28 named models with Japanese mesh lettering and vermilion promotion faces. Ownership uses tile direction and a shared body colour. Their 9x9 and 5x5 physical kaya-coloured boards have rectangular cells, continuous grain, native edge notation, legs, shadows, and dimension-aware camera framing. See `ops/assets/shogi/README.md`.
- Setup uses tactile buttons for clocks and sides, and a disclosure with real choice buttons for long bot/family lists. Appearance uses visual presets. The 2D board has a single tab entry and arrow-key square navigation.
- Friend invites connect two browsers through authoritative room actions: assigned seats, legal moves and drops, server clocks, agreed draws, resignation, rejoining, spectator views, and private player messages. Snapshots have monotonically increasing revisions so slower responses cannot overwrite newer state.
- Coordinated rematches keep the invite and both players, require mutual acceptance, swap sides, and reset the board/clocks. Per-game IDs reject delayed actions from an earlier game. Offers can be cancelled; chat keeps participant identity across side changes. Connection feedback covers offline/reconnecting/unavailable states, bounded requests, automatic recovery, manual retry, and last-seen friend presence. Server clocks continue during disconnection.
- Production rooms use the existing `GAME_ROOM_DO` binding, serialized storage transitions, hashed seat credentials, and seven-day expiry with a storage alarm. The bounded in-memory fallback is restricted to development/test. Production without the binding returns unavailable instead of pretending a local room is online.
- Installable manifest, regular/maskable icons, browser install prompt, and a downloadable offline play pack (about 22.5 MiB). A public static shell reuses all 21 playable board adapters, local bots including Stockfish, themes, and the three 3D collections. Cold launches work after download. Build-generated hashes verify every file before replacing a working pack. Private pages, APIs, RSC responses, room state, and account information are excluded. See `offline-play-pack.md`.
- Local and bot matches now autosave to device storage, including complete undo/redo timelines, clocks, settings, drops, promotions, and variant rule state. Resume controls are available in the library, per-game setup, and offline studio. Local clocks pause while away; opening a saved link waits for Resume. Atomic revision checks protect against another window overwriting progress, with latest-save and separate-copy recovery. See `local-match-saves.md`.
