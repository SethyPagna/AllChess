# Carved (Hori) model source

An original contemporary honey-boxwood interpretation of one-character carved Shogi pieces, shared by Shogi and Mini Shogi. It is not a named artisan replica. Both owners use the same wood and lettering colours; their pointed ends indicate direction. Sente's king carries 玉 and Gote's 王. Base faces are 玉/王, 飛, 角, 金, 銀, 桂, 香 and 歩; promotion faces are 竜, 馬, 全, 圭, 杏 and と. These abbreviations follow the [Japan Shogi Association rules](https://www.shogi.or.jp/match/taikyoku_rules/).

The [JSA's one-character carved boxwood set](https://store.shogi.or.jp/view/item/000000001687), [Tendō's account of the craft](https://www.city.tendo.yamagata.jp/tourism/shogi/tenndoutosyougikoma.pdf) and [Satō's manufacturing/dimension guide](https://shogi-koma.jp/?mode=f5) support the material, pentagonal wedge, size hierarchy and carved/lacquered construction. The last source lists king length/width/thickness 31.5/28/9.5 mm and pawn 27/22.5/7.75 mm. This app uses an adapted, larger footprint for its 53×57 mm board cells, with a 33×39 mm king and 26.5×33.4 mm pawn. Maximum thickness is 11.3 mm, preserving the existing 12 mm captured-tile stack spacing.

`build_hori.py` authors real blind glyph recesses, their wood walls/floors, thin inset lacquer and fine softened edges. Recess depth is 0.42 mm. Promotable pieces have physically recessed paired underside lettering; king and gold reverses remain blank. A promoted semantic root presents the promoted face upward in the same stable resting pose. The application selects the explicit root from game state; rendering does not infer promotion from a mesh flip.

Letter meshes use **Noto Serif CJK JP Bold**, copyright 2017–2024 Adobe, SIL OFL 1.1; see [FONT-LICENSE.txt](FONT-LICENSE.txt). The pinned upstream file is [NotoSerifCJKjp-Bold.otf](https://github.com/notofonts/noto-cjk/blob/main/Serif/OTF/Japanese/NotoSerifCJKjp-Bold.otf), SHA-256 `861a2b2c0e24b23745c262be8c3fdef63f12628f0492fb120ee51aa55c503af8`. A restrained 12-font-unit outline expansion preserves the Serif character while strengthening horizontal hairlines at playing size. The expanded contours are united before extrusion, keeping counters open and eliminating overlapping stroke surfaces. Original licensed text curves and the converted meshes remain editable in the Blender source. Generated 2D masters guide the collection's silhouette and material; their brush lettering may differ from the verified Noto outlines used in 3D.

Original longitudinal-fibre and endgrain shaders bake into portable colour, roughness and normal images. The normal bake helpers match the physical UV scales: 40×48 mm for longitudinal grain and 40×12 mm for endgrain. This preserves restrained microscopic relief through 8-bit texture encoding. Roughness and normal intermediates use lossless PNG so later colour-only iterations preserve their values. Their procedural nodes and packed images remain in `hori.blend`. Sumi and vermilion lacquer have their own solid PBR materials, named `ink` so alternative finishes retain legible native lettering. No remote textures or runtime font downloads are required.

Rebuild from the repository root with Blender 5.2:

```
blender -b -t 4 --python ops/assets/shogi/build_hori.py
```

The pinned font must be present at `output/playwright/shogi-font/NotoSerifCJKjp-Bold.otf`. Install the isolated outline tools using Blender's bundled Python: `python -m pip install --target output/atelier/hori/vendor fonttools==4.66.0 shapely==2.1.2`. These builder-only dependencies do not enter the application. Default rebuilds rebake every procedural map. `-- --reuse-bakes` reuses unchanged maps; add `--refresh-colour` to rebake only colour while preserving roughness and normals. `--stage` writes a full collection to ignored scratch paths for review before publication. `--prototype` writes a scratch king/pawn carving proof and an approximately 40-pixel king-width render. Intermediate maps, validation data and prototype renders live in ignored `output/atelier/hori`. Delivery is `public/assets/shogi/hori.glb`, with the existing 28 semantic roots, plus editable `hori.blend` and `hori-preview.png`.
